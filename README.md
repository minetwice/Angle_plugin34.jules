# Diablo Smp Plugin

This is a high-quality Minecraft Paper plugin (1.21-1.21.4) featuring advanced abilities, secure item management, and unique social mechanics.

## Features
- **Multi-Stage Ability System**: Switch between 3 stages per ability by double-sneaking.
- **Soul Shackle**: A unique possession ability that allows you to control other entities while leaving your body as an invulnerable statue.
- **Secure Ability Books**: Power items that cannot be dropped or stored unless a trust contract is active.
- **Trust System**: Use `/trust <player>` to allow trading ability books for 5 minutes.
- **Absorption GUI**: Right-click ability books to open a custom absorption interface with cinematic effects.

## Commands
- `/diablo give <player> <ability>`: Give an ability book (Admin).
- `/trust <player>`: Start a 5-minute trade window.
